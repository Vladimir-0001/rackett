Connection guide

Connect Sonarr, Radarr and more

  1. Add a Torznab indexer in your app

    In Sonarr or Radarr, open Settings → Indexers, add a Torznab indexer, then fill in the fields below.

  2. It searches every enabled source. For a single source, open that source’s menu and choose Copy Torznab URL.

  3. Enter your API key

    Your private integration key is in Settings.
